# AARVIFY TECH SERVICES Website

This is a premium, SEO-optimized React application for AARVIFY TECH SERVICES PRIVATE LIMITED, specializing in debt recovery and financial services.

## Features

- **SEO Optimized**: Includes React Helmet for meta tags, JSON-LD schemas (Organization, LocalBusiness, JobPosting, breadcrumbs).
- **Responsive Design**: Built with Tailwind CSS, fully mobile-friendly.
- **Premium UI**: Clean, modern aesthetics with Framer Motion animations.
- **Form Validation**: Uses React Hook Form.
- **Email Integration**: Setup for EmailJS (see `.env.example`).
- **Performance**: Code splitting with React Lazy/Suspense.

## Tech Stack

- React 18+ (Vite)
- TypeScript
- Tailwind CSS
- React Router DOM
- Framer Motion
- Lucide React (Icons)
- React Helmet Async

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Setup EmailJS:
   - Create an account at [EmailJS](https://www.emailjs.com/).
   - Create a service and a template.
   - Copy your Service ID, Template ID, and Public Key to a `.env` file (refer to `.env.example`).

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Folder Structure

- `src/components`: Reusable UI components.
- `src/pages`: Individual page components (7 total).
- `src/assets`: Images and icons.
- `src/utils`: Helper functions and schemas.
- `src/index.css`: Tailwind and global styles.
